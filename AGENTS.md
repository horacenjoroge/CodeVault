# CodeVault Landing Page Instructions

## Brand
CodeVault is a software development studio for founders, startups, small businesses, and focused teams.

Positioning:
CodeVault builds the digital systems behind serious businesses.

Services:
- Landing pages
- SaaS MVPs
- Dashboards
- Web apps
- Mobile apps
- Chrome extensions
- AI tools
- Automations
- APIs
- Production fixes
- Deployment setup

## Design Direction
Keep the site minimal, editorial, serious, and high-trust.

Use:
- Large bold typography
- Strong whitespace
- Thin dividers
- Forest green accent
- Black / white / grey palette
- Clear section labels
- Conversion-focused copy
- Subtle motion
- Very few decorative elements

Avoid:
- Generic freelancer copy
- Fake testimonials
- Fake metrics
- Random stock photos
- Colorful gradients
- Excessive cards
- Overdesigned effects
- Copying Reduzer too closely

## Copy Rules
Write like a serious software partner, not a junior freelancer.

Focus on:
- Clear scope
- Practical delivery
- Visible progress
- Clean handoff
- Ownership
- Production readiness
- Business outcomes

Use “we” and “CodeVault,” not mostly “I.”

## Code Rules
- Keep the page responsive.
- Avoid heavy dependencies.
- Use semantic HTML.
- Ensure keyboard accessibility.
- Respect prefers-reduced-motion.
- Avoid horizontal overflow.
- Keep components/styles easy to edit.
- Use reusable Astro components.
- Keep JavaScript minimal.
